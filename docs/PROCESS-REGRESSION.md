# Регрессионная проверка чтения CLI

Сборка использует системный компилятор .NET Framework, C# 5, Windows x64. Новых зависимостей нет.

Проверки загружают указанный готовый EXE через reflection. Они не пересобирают проверяемое приложение. `CliStub.cs` создаёт тестовые процессы. Временная база содержит только искусственные данные. Установленные CLI, аккаунты и реальные базы в этих проверках не используются.

```powershell
.\Check-Local.ps1
.\tests\Run-Regression.ps1 -Binary .\dist\AIUsageTray.exe -OutputRoot "$env:TEMP\tray-regression-unique"
```

`OutputRoot` должен быть новым каталогом. Проверки сохраняют результаты и не очищают прежние каталоги.

Проверяется таймаут, отмена, потомок с открытым каналом после выхода родителя, запрет параллельного чтения, повторное успешное чтение, завершение тестовых потомков и сохранение отдельного контрольного процесса. Проверяется отсутствие искусственного секрета в сообщениях об ошибках.

Для версии с Claude дополнительно проверяются единицы `utilization`: значения `0`, `0.5`, `1`, `1.01`, `100` должны дать остаток `100`, `99.5`, `99`, `98.99`, `0`. Значения вне диапазона и нечисловые значения отклоняются.

В версии 2.0.0 можно добавить `-Gui` в пользовательском сеансе Windows. Проверка создаёт собственный значок, меню и карточку из указанного EXE. Провайдеры используют искусственные ответы. Проверяются проценты Claude, сохранение последнего результата, устаревание, переключение во время запроса, освобождение ресурсов и отдельный запуск/выход самого EXE. Изображения меню и карточек сохраняются в `OutputRoot`.

`LiveReadTests.cs` — отдельная ручная по запуску проверка доступности провайдеров и штатного чтения квот Codex/Claude. Она требует явного разрешения на реальные запросы. Она не читает реальную базу OpenCode и не отправляет запросы к моделям. Не включайте её в автоматические изолированные тесты.
