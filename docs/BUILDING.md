# Сборка и выпуск

## Требования

- Windows x64.
- .NET Framework 4.8.1.
- PowerShell.

Пакеты NuGet не нужны. Компилятор C# входит в .NET Framework.

## Локальная сборка

Запустите из корня проекта:

~~~powershell
.\Check-Local.ps1
~~~

Скрипт собирает приложение: компилирует все файлы `src/*.cs` системным `csc.exe` (C# 5,
`/warnaserror+`). Чтобы добавить модуль, положите новый файл `src/*.cs` — правки сборочного
скрипта не нужны.
Готовое приложение появится в dist/AIUsageTray.exe.

Каталог dist/ исключён из Git. Не добавляйте его содержимое в коммиты.

## Изолированные проверки

`Check-Local.ps1` удаляет старый `dist/` перед сборкой. Запустите сборку и проверки T7:

~~~powershell
.\Check-Local.ps1 -Tests
~~~

Проверки находятся в `tests/T7/`, используют временную SQLite-базу и тестовую команду
`opencode.exe`; пользовательская база, сеть и живой OpenCode не используются. Нужен
`sqlite3.exe` в `PATH` или в Android SDK.

## Публикация

Создайте GitHub Release для нового тега и прикрепите dist/AIUsageTray.exe как asset.
Не коммитьте бинарный файл в исходный репозиторий.
GitHub Release также предоставляет архив исходников для выбранного тега.
