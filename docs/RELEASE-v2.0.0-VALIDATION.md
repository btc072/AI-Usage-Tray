# Проверка исправленного v2.0.0

Дата: 22 октября 2026 года. Исходная версия: `6bed4cb7f3d54bb975beedb4b901634bad84f0e3`.

Выпуск не включает последующую разработку Zen. Совместимое исправление Codex передано отдельно в main. Исправления Codex, Claude и OpenCode также переданы в ветку 2.0.0 с сохранением Zen.

## Исправления

- Claude `utilization` читается в процентах. Значения `0`, `0.5`, `1`, `1.01`, `100` дают остаток `100`, `99.5`, `99`, `98.99`, `0`.
- CLI запускается приостановленным. Он попадает в отдельный Job Object до возобновления. Его потомки принадлежат тому же заданию. Приложение не использует завершение процессов по имени или `taskkill`.
- Вывод читается через канал с проверкой отмены. Открытый канал потомка не удерживает чтение после отмены или таймаута. Защита от параллельных чтений и последнее успешное значение сохранены.

## Проверки

На EXE из исходного коммита воспроизведены ошибка Claude и блокировка обоих reader при таймауте, отмене и выходе родителя. Исходный прогон: 2 успешных сценария и 7 ошибок.

На готовом исправленном EXE прошли 9 регрессионных сценариев. Каждый сценарий чтения также проверяет запрет параллельного чтения, сохранение постороннего контрольного процесса, отсутствие оставшихся тестовых потомков и восстановление следующего чтения. Искусственный секрет не появляется в сообщениях об ошибках.

GUI проверен в пользовательском сеансе Windows. Проверки загружают именно публикуемый EXE. Проверены регистрация значка, меню трёх провайдеров, карточка Claude с остатком 99.5%, сохранение последнего результата, отметка устаревания, переключение во время запроса и освобождение ресурсов. Сам EXE также отдельно запущен и штатно закрыт через окно собственного экземпляра.

Основная ветка прошла 4 сценария Codex. Ветка с Zen прошла 9 сценариев и 117 существующих проверок T7. В первом параллельном прогоне main один сценарий не дождался запуска тестового потомка. Последовательный повтор прошёл. Ожидание готовности теста увеличено с 3 до 5 секунд; ограничения времени отмены не менялись. Итоговый последовательный прогон прошёл.

Два раунда независимого ревью: по два свежих рецензента на раунд. Области: корректность/совместимость и безопасность/изоляция тестов. Модель `gpt-6-luna`, effort `medium`. Итоговые оценки: 9/10 у всех четырёх рецензентов. Подтверждённых открытых замечаний нет. Замечание о потере окружения отклонено: getter `ProcessStartInfo.EnvironmentVariables` наследует окружение; это подтверждено отдельной проверкой .NET и работой CLI.

Сканирование исходников Gitleaks не нашло секретов. Сборки выполнены системным `csc.exe`, C# 5, x64, с предупреждениями как ошибками.

## Границы проверки

Реальное чтение квот Codex прошло на окончательном EXE. Чтение квот Claude оказалось недоступно; реальные значения Claude не подтверждены. Реальная база OpenCode не использовалась. Условие с удерживаемым каналом воспроизведено тестовыми процессами; это не утверждение о каждом установленном CLI.

Windows x64 и установленный .NET Framework проверены на текущем компьютере. Другие компьютеры, чистая установка Windows и SmartScreen не проверены.
