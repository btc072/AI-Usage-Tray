# AI Usage Tray

[Русский](README.ru.md) | [English](README.md)

Компактная утилита для Windows, которая показывает остаток лимитов Codex и Claude, а также расход токенов и оценку стоимости OpenCode за сегодня, прямо в системном трее. Каждый запуск создаёт свой значок, а провайдер выбирается в меню значка. Карточка по наведению показывает подробности.

Для запуска нужен один файл `AIUsageTray.exe`. Утилита использует уже установленные и авторизованные клиенты.

## Возможности

- Две строки на каждом значке. У Codex и Claude сверху пятичасовой лимит, снизу недельный; у OpenCode сверху токены за сегодня, снизу оценка стоимости.
- У Codex и Claude цвет каждой строки зависит от остатка лимита; строки «5 часов» и «Неделя» используют тот же статусный цвет целиком. Строки OpenCode — это расход, а не лимит, и остаются нейтральными.
- Заголовок карточки `<Провайдер> · ТАРИФ`; тариф показывается ПРОПИСНЫМИ буквами и жирным шрифтом.
- Ручной выбор провайдера в меню значка: обнаруженные пункты яркие и выбираются, необнаруженные серые.
- Карточка открывается после 500 мс непрерывного наведения; уход указателя до показа отменяет открытие.
- Количество доступных ручных сбросов и сроки действия полученных записей (Codex).
- Срок подписки, если он доступен в сохранённых метаданных Codex.
- Системный шрифт, светлая или тёмная тема Windows, компактная ширина по содержимому.
- Русский и английский интерфейс с автоматическим выбором языка.
- Обновление данных раз в 60 секунд и отметка устаревших данных при сбое.

## Требования

- 64-разрядная Windows. Текущая сборка проверена на Windows 11.
- .NET Framework 4.8.1.
- Хотя бы один поддерживаемый клиент, установленный и авторизованный:
  - **Codex** с нативным `codex.exe`, который поддерживает `app-server`;
  - **Claude** — Claude Code или Claude Desktop с выполненным входом. Основной источник — Claude Code; токен Claude Desktop — зашифрованный blob и может не дать пригодный токен доступа;
  - **OpenCode** с CLI и локальной базой.
- Codex и Claude должны иметь доступ к своему сервису; OpenCode читает локальную базу.

Программа обнаруживает каждый клиент через `PATH`, каталог установки или сохранённые учётные данные. Окно самого клиента может быть закрыто.

## Запуск

Текущий публичный выпуск — [v2.0.0](https://github.com/btc072/AI-Usage-Tray/releases/tag/v2.0.0), он поддерживает Codex, Claude и OpenCode. Более ранний выпуск [v1.0.0](https://github.com/btc072/AI-Usage-Tray/releases/tag/v1.0.0) следит только за Codex.

1. Установите и авторизуйте хотя бы один поддерживаемый клиент.
2. Скачайте текущий выпуск или соберите утилиту из исходников по инструкции ниже.
3. Запустите EXE двойным щелчком. Каждый запуск создаёт свой значок. Если значок оказался в области скрытых значков, откройте её и при желании перенесите значок на панель задач.

Дополнительные файлы рядом с EXE не нужны. Повторный запуск создаёт ещё один значок и не останавливает и не заменяет уже запущенные.

Правый щелчок по значку открывает меню со списком провайдеров. Установленный и авторизованный провайдер показан ярко и выбирается; необнаруженный — серый и выбрать его нельзя. Значок следит за выбранным для него провайдером, и выбор не влияет на другие значки. До выбора значок подключается к первому обнаруженному провайдеру в порядке Codex → Claude → OpenCode. Если не обнаружен никто, карточка показывает **«Нет провайдера»** и предлагает выбрать провайдера в меню. Выбор хранится только в памяти; после перезапуска значок снова связывается по умолчанию. **«Выход»** закрывает этот значок.

Наведите указатель на значок, чтобы открыть карточку. Она остаётся открытой при переводе указателя с значка на карточку и скрывается через 500 мс после ухода. `Esc` скрывает карточку.

### Совместный запуск с Codex

Для настольного приложения Codex в Windows доступен режим `--with-codex`: он открывает Codex и запускает индикатор в трее. Повторное использование ярлыка открывает Codex и создаёт ещё один значок индикатора.

1. Положите EXE в постоянную папку, например %LOCALAPPDATA%\Programs\AIUsageTray\AIUsageTray.exe.
2. Создайте ярлык на этот файл. В свойствах ярлыка добавьте `--with-codex` в конце поля **«Объект»**:

   ```text
   "%LOCALAPPDATA%\Programs\AIUsageTray\AIUsageTray.exe" --with-codex
   ```

3. Запускайте Codex через этот общий ярлык.

Обычный запуск EXE без параметра открывает только индикатор. Совместный режим использует зарегистрированное приложение `OpenAI.Codex_2p2nqsd0c76g0!App`, поэтому путь запуска не зависит от номера установленной версии Codex. Способ активации через `shell:AppsFolder` описан в [документации Microsoft](https://learn.microsoft.com/en-us/windows/apps/distribute-through-store/how-to-transition-users-from-your-web-unpackaged-app-to-store-packaged-app#how-to-launch-the-store-application-from-your-web-unpackaged-app).

## Что показывает значок

На значке отображается **оставшийся** лимит у Codex и Claude. Цвет каждой строки определяется отдельно.

| Остаток | Цвет |
| --- | --- |
| Более 30% | Зелёный |
| Более 10%, до 30% включительно | Жёлтый |
| 10% и меньше | Красный |
| Достоверных данных нет | Серый прочерк |

У OpenCode значок показывает сверху токены за сегодня, снизу оценку стоимости, нейтральными цветами (не по шкале лимитов). Фон значка прозрачный, цифры непрозрачные. Неизвестное значение показывается прочерком и не подменяется нулём.

## Карточка

Все строки выровнены по центру; строки с процентами выделены жирным шрифтом. Ширина окна подбирается по тексту. Справа и до панели задач оставлен одинаковый отступ 6 пикселей. Заголовка окна и системных кнопок нет. Даты показываются в часовом поясе Windows.

Заголовок — `<Провайдер> · ТАРИФ`, тариф показывается ПРОПИСНЫМИ буквами и жирным шрифтом. Без тарифа показывается только имя провайдера (например, `Claude` или `OpenCode`).

Ниже приведены демонстрационные данные. Состав строк зависит от ответа провайдера.

**Русский интерфейс:**

```text
Codex · PLUS

5 часов - 75%
До сброса: 3 ч 20 мин
Сброс: 01.01.2030 18:00

Неделя - 20%
До сброса: 2 дня 8 ч 20 мин
Сброс: 03.01.2030 23:00

Сбросов лимитов: 1
До: 31.01.2030 23:59

Подписка до: 31.01.2030 23:59
```

**English interface:**

```text
Codex · PLUS

5 hours - 75%
Time to reset: 3 h 20 min
Reset: 01.01.2030 18:00

Week - 20%
Time to reset: 2 days 8 h 20 min
Reset: 03.01.2030 23:00

Limit resets: 1
Until: 31.01.2030 23:59

Subscription until: 31.01.2030 23:59
```

Claude показывает те же строки лимитов со своим тарифом.

**OpenCode (русский интерфейс):**

```text
OpenCode

Токены за сегодня - 1 234 567
Стоимость за сегодня (оценка) - $12.34

OpenCode не запущен; данные из локальной базы
```

Сервис может вернуть количество сбросов без подробного списка. Строки со сроками показываются при наличии соответствующих записей. Сохранённый срок подписки может устареть; это не подтверждённая дата следующего платежа.

### Выбор языка

Язык выбирается при запуске по языку интерфейса Windows **или региональному формату**:

- **Русский**, если хотя бы одна из этих настроек относится к Армении, Азербайджану, Беларуси, Эстонии, Грузии, Казахстану, Кыргызстану, Латвии, Литве, Молдове, России, Таджикистану, Туркменистану, Украине или Узбекистану.
- **Английский** во всех остальных случаях.

Например, английский интерфейс Windows с русским региональным форматом включает русский язык программы. После изменения настроек языка перезапустите утилиту.

## Получение данных

Раз в 60 секунд утилита читает выбранного провайдера. Собственных файлов она не создаёт и настройки Windows не меняет.

- **Codex** — запускает скрытый дочерний процесс `codex app-server --listen stdio://` и читает лимиты через `account/rateLimits/read` (тариф — через `account/read` при необходимости). У запроса тайм-аут 15 секунд, после чтения процесс завершается; опросы не перекрываются. Запросы к модели и ручные сбросы лимитов не выполняются. Метаданные подписки читаются локально из сохранённых данных авторизации Codex.
- **Claude** — читает лимиты через OAuth usage endpoint, который использует Claude Code, по сохранённому токену Claude Code, а при его отсутствии — по токену Claude Desktop. Endpoint неофициальный и может измениться. Без пригодного сохранённого токена живые лимиты показать нельзя.
- **OpenCode** — читает локальную базу через официальный CLI `opencode db` (сеть не используется) и показывает токены и оценку стоимости за сегодня. Стоимость — оценка и может расходиться с биллингом сервиса; это не лимит.

Учётные данные читаются только в память и никогда не копируются и не сохраняются. При ошибке остаётся последний успешный результат; предупреждение появляется при сбое или возрасте данных от 120 секунд. Обратный отсчёт обновляется только при открытой карточке.

Статусы: если клиент не запущен, но учётные данные есть, карточка показывает нейтральную строку, например «Codex не запущен; данные из сохранённого входа» (OpenCode — «данные из локальной базы»). Если провайдер исчез полностью после успешного чтения, карточка сохраняет последний снимок и добавляет «данные не поступают; провайдер неактивен»; без снимка — «нет данных». Неизвестные данные показываются как «нет данных» и никогда как 0 % или 100 %.
